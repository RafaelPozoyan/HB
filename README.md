# Сайт-поздравление для Алины

## Запуск
1. Распакуй архив.
2. Открой папку `alina-birthday-project` в VS Code.
3. Установи расширение **Live Server**.
4. Открой `index.html` → правый клик → **Open with Live Server**.

## Где что находится
- `index.html` — содержимое главной страницы.
- `css/style.css` — внешний вид, тема и анимации.
- `js/script.js` — интерактивность и эффекты.
- `pages/memories.html` — пример отдельной страницы.
- `assets/images/` — фотографии.
- `assets/music/` — музыка.
