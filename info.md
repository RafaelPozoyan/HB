# README — Сайт-поздравление «С днём рождения, Алина!»

## Назначение

Одностраничный (с несколькими подстраницами) статический сайт-поздравление с днём рождения для Алины. Романтический, интерактивный, на русском языке. Контент — личный, часть текстов оставлена как заглушки `ВСТАВЬ СЮДА ТЕКСТ`.

## Стек

- **Чистый статический HTML/CSS/JS** — без сборки, без фреймворков, без npm.
- **Главная (`index.html`)** использует **Tailwind CSS через CDN** (`cdn.tailwindcss.com`) + инлайн-конфиг в `<script>`.
- **Подстраницы (`pages/*.html`)** Tailwind **не используют** — только собственные CSS-файлы (`css/style.css`, `css/pages.css`).
- **Шрифт**: Inter (Google Fonts), только на главной.
- **Деплой**: любой статический хостинг (GitHub Pages, Netlify, Vercel, обычный веб-сервер). Сборка не требуется.

## Функциональность

### Главная (`index.html`)
- **Авторизация**: форма логин/пароль. Хардкод-проверка `login === '1' && password === '1'`. При успехе экран плавно исчезает и удаляется из DOM. **Это не безопасность, а декоративный гейт** — любой, кто откроет исходник, увидит пароль.
- **Индикатор прокрутки** — `#progress`, обновляется на `scroll`/`resize`.
- **Reveal-анимации** через `IntersectionObserver` (класс `.reveal` → `.visible`).
- **Форма желания** (`#wish-form`): POST на `https://formsubmit.co/ajax/pozoyan.2000@gmail.com` через `fetch`, JSON `{_subject, message, _captcha: 'true'}`. Кнопка дизейблится на время запроса, статус пишется в `#wish-status`. Адрес почты захардкожен в клиенте.
- **Fallback фото**: у `<img>` в `onerror` подставляются картинки с Unsplash, если локальные `assets/images/photoN.png` не найдены.
- Tailwind-классы для вёрстки + кастомные классы (`.glass`, `.primary-button`, `.photo-frame` и т.д.) в `<style>`.

### Подстраницы (`pages/*.html`)
- Общий `nav` со ссылками на все разделы, активный пункт помечен классом `.active` вручную.
- `life/travels/loved-ones` — одинаковый шаблон: `page-heading` + `content-grid` из двух карточек-заглушек.
- `date.html` — кнопка `#accept`, по клику пишет в `#response` текст «Приглашение принято!».
- `memories.html` — минимальная страница, подключает `js/script.js`, но разметки под него нет.

## Как запустить

Статикой, без сборки:

```bash
# любой статический сервер из корня проекта
python3 -m http.server 8000
# или
npx serve .
```

Открыть `http://localhost:8000/`. Открытие через `file://` тоже работает, но formsubmit/fetch и некоторые браузерные политики могут вести себя иначе — лучше через http-сервер.

## Известные особенности и подводные камни

1. **Дублирование логики**: `index.html` содержит инлайн-JS (прогресс, reveal, форма желания, авторизация), а `js/script.js` — свою версию похожей логики для подстраниц. Часть селекторов в `script.js` (`#stars`, `#progress`, `#magic`, `#show-wish`) на реальных страницах отсутствует → код в этих местах падает/не выполняется. `script.js` фактически «мертвый» для текущей разметки, кроме, возможно, `DOMContentLoaded`-блока формы желания (но и его элементов на memories.html нет).
2. **Два разных CSS-подхода**: главная — Tailwind CDN + инлайн `<style>`; подстраницы — `style.css` + `pages.css`. Классы пересекаются по именам (`.photo-frame`, `nav`, `.reveal`), но определены по-разному → стили главной и подстраниц не совпадают визуально.
3. **Битые ссылки**: `pages/beautiful.html`, `pages/smart.html`, `pages/letter.html` — в наборе отсутствуют.
4. **Авторизация небезопасна** по замыслу (пароль в клиенте). Если сайт публичный — это просто «занавеска», не защита.
5. **FormSubmit**: первый POST может требовать подтверждения email владельца; `_captcha: 'true'` включает капчу formsubmit. При ошибке сети показывается сообщение об ошибке.
6. **Заглушки контента**: на подстраницах множество `ВСТАВЬ СЮДА ТЕКСТ` — контент не доделан.
7. **`prefers-reduced-motion`** учтён и на главной, и в `style.css` — анимации отключаются.
8. **`index.html` не подключает `css/style.css` и `js/script.js`** — это осознанно, главная самодостаточна.
